# Структура директорий

- `perf_analysis` - директория, содержащая результаты анализа
  производительности отдельных этапов приложения для определения
  текущей локации.
  - `benchmark_results.md` - результаты производительности.

- `tutorials` - инструкции с описанием последовательности загрузки
  различных баз данных.
  - `LoadAttactionsDB_OSM.md` - последовательность загрузки
    базы достопримечательностей из OSM.
  - `LoadAdminUnitsDB_OSM.md` - последовательность загрузки
    базы административно-территориальных единиц из OSM.

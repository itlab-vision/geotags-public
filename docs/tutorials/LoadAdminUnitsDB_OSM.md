# Инструкция по загрузке базы данных административно-территориальных единиц

Данные загружаются с сайта [OSM-Boundaries][osm-boundaries].

## Загрузка базы данных

Загрузка базы данных с сайта [OSM-Boundaries][osm-boundaries] включает следующую последовательность действий.

1. Зарегистрироваться на указанном сайте.
1. Отметить интересующие административные единицы. При выборе российских
   административно-территориальных единиц следует руководствоваться рекомендациями и учитывать
   некоторые особеннности базы, приведенные в примечаниях.
1. Нажать кнопку `Download`. В результате откроется окно, в котором необходимо проконтролировать
   следующие моменты:
    - Выбран ли пункт `use map selection`, который позволит скачать только выделенные ранее границы.
    - Хватает ли числа токенов на загрузку этих границ _(в бесплатном плане ограничение в 500 токенов в день)_\*.
    - Убедиться, что выбран нужный административный уровень (`admin level`). По ним также можно отфильтровать
      выбранные административные единицы.
    - Выбран формат выхода GeoJSON, чтобы далее использовать внутренний скрипт `parse_admin_units_db.py`
      для перевода данных из указанного формата в формат JSON.
    - Выбран корректный уровень упрощения границ (`simplify`), если можно пожертвовать их точностью.

   После нажатия на `Download` скачается файл с расширением `*.geojson`.

**Примечание:** на момент написания документации (26.02.2026) доступна подписка Explorer, которая выдаётся
бесплатно во время бета-тестирования и расширяет лимит до 10000 токенов в день.

### Рекомендации

- При скачивании административно-территориальных единиц РФ отмечать только те, которые указаны в базе данных
  для данной страны.
- Административный уровень выделенного объекта указан возле его названия в общем списке.

#### Субъекты РФ:

- Административный уровень (`admin_level`) равен четырем.
- Поселок `Чернореченский` выделен отдельно от `Кировской области`, поэтому его не нужно выделять,
  так как он уже входит в состав `Кировской области`.
- Севастополь продублирован, выделить нужно только один.
- Саров является единицей закрытого административно-территориального образования и является административной
  единицей, но отдельно выбран не был, так как он является частью Нижегородской области. Территориально находится
  на границе Нижегородской области и Республики Мордовия.

#### Города РФ:

- При поиске на русском стоит вписывать: "<город>", "городской округ <город>". 
  - В некоторых случаях имя города склоняется: "Семёновский городской округ".
  - У некоторых городов отсутствует английский вариант именования.
- Административный уровень (`admin_level`) равен шести и в некоторых случаях четырём.
  - Города федерального значения имеют четвертый административный уровень,
    так как являются субъектами РФ.
- Стоит помнить, что выгружая городские округа, они могут включать в себя ещё другие посёлки и деревни,
  поэтому площадь может намного превышать размеры самого города.


### Общий перечень атрибутов

Ниже приведен перечень атрибутов, которыми описываются административно-территориальных единицы в файле `*.geojson`.

Общие атрибуты:
- `properties` - общая информация об административно-территориальной единице в базе данных:
    - `osm_id` - идентификатор административно-территориальной единицы в БД OSM,
    - `name` - название административно-территориальной единицы на языке страны,
    - `name_en` - название административно-территориальной единицы на английском языке,
    - `boundary` - тип границ (по умолчанию "административные"),
    - `admin_center_node_id` - идентификатор административного центра в БД OSM,
    - `admin_center_node_lat` и `admin_center_node_lng` - координаты административного центра
- `geometry` - общая информация о геометрии административной единицы:
    - `type` - тип геометрии (полигон/мультиполигон),
    - `coordinates` - координаты вершин полигона/мультиполигона.

## Конвертация базы из формата `*.geojson`

Для конвертации базы административно-территориальных единиц в csv-формат для последующего использования
в проекте необходимо использовать скрипт `scripts\parse_admin_units_db.py`.

Командная строка для запуска скрипта:
```bash
python parse_admin_units_db.py -i <путь к файлу *.geojson> -o <название выходного файла>
```

В результате работы скрипта создается файл в формате csv с названием `<название выходного файла>`.
Атрибуты записей в выходном файле:

- `name_en` - название административно-территориальной единицы на английском языке.
- `name` - название административно-территориальной единицы на языке страны.
- `wkt` - конвертированные координаты полигонов/мультиполигонов административно-территориальной единицы
  из формата JSON в формат WKT (Well-known text) для удобства хранения.

# Запуск приложений

## Приложение для извлечения широты и долготы локации из Exif

```bash
./build/getcoordinates_app -i=<path/to/image.jpg>
```

Для запуска приложения необходимо передать путь до изображения (ключ `-i`).

## Приложение для определения текущей локации

```bash
./build/geotags_app -i=<path/to/image.jpg> \
                    -t=<reader_type> \
                    -f=<path/to/coordinates.csv> \
                    -d=<distance_type> \
                    -st=<search_type> \
                    -s
```

Для запуска приложения необходимо передать путь до изображения (ключ `-i`)
и до файла в формате `.csv` или `.csv.fb` (ключ `-f`) с координатами городов,
формат входных данных (ключ `-t`), а также тип метрики для оценки расстояния
между локациями (ключ `-d`) и алгоритм поиска ближайшей локации (ключ `-st`).

В результате работы выводятся данные по текущей локации и переданное изображение, для отключения вывода изображения используется ключ `-s`.

Возможные значения метрики:

- `haversine` - метрика гаверсинуса, которая напрямую рассчитывает длину дуги на сфере,
- `haversine_approx` - аппроксимация метрики `haversine`, которая может
  использоваться при небольших расстояниях между парой объектов.

Возможные алгоритмы поиска ближайшей локации:
- `linear` - линейный проход по всем локациям,
- `grid` - база локаций предварительно разбивается на сегменты с использованием равномерной
  сетки, выполняется линейный проход по целевому и соседним сегментам,
- `grid_binary` - база локаций предварительно разбивается на сегменты с использованием равномерной
  сетки, выполняется бинарный поиск в целевом и соседних сегментах.

Примеры запуска для разных версий проекта:

Версия 1.0
```bash
./build/geotags_app -d=haversine \
                    -f=<path/to/coordinates.csv> \
                    -i=<path/to/image.jpg> \
                    -t=csv \
                    -st=linear \
                    -s
```

Версия 2.0 | 2.1
```bash
./build/geotags_app -d=haversine \
                    -f=<path/to/coordinates.csv> \
                    -i=<path/to/image.jpg> \
                    -t=csv_fb \
                    -st=linear \
                    -s
```

Версия 3.0
```bash
./build/geotags_app -d=haversine \
                    -f=<path/to/coordinates.csv> \
                    -i=<path/to/image.jpg> \
                    -t=csv_fb \
                    -st=grid|grid_binary \
                    -s
```

## Приложение для поиска ближайшей достопримечательности

```bash
./build/attractions_app -i=<path/to/image.jpg> \
                        -t=<reader_type> \
                        -f=<path/to/city_attraction.csv> \
                        -d=<distance_type> \
                        -st=<search_type> \
                        -s
```

Приложение демонстрирует двухэтапный поиск:

1. Определение ближайшего города по координатам из Exif-данных изображения. Файл
   `<path/to/city_attraction.csv>` (ключ `-f`) содержит перечень наименований и локаций
   городов, а также соответствующих им баз достопримечательностей.
1. Поиск ближайшей достопримечательности в базе найденного города.

Для запуска приложения необходимо передать путь до изображения (ключ `-i`), путь до файла с описанием баз
достопримечательностей городов в формате `.csv` или `.csv.fb` (ключ `-f`), формат входных данных (ключ `-t`),
метрику для расчета расстояния (ключ `-d`), а также алгоритм поиска ближайшего объекта (ключ `-st`).

В результате работы выводятся координаты, дата съемки, название найденной достопримечательности и расстояние
до неё, а также затраченное время. Для отключения вывода изображения используется ключ `-s`.

Возможные значения метрики:

- `haversine` - метрика гаверсинуса, которая напрямую рассчитывает длину дуги на сфере,
- `haversine_approx` - аппроксимация метрики `haversine`, которая может
  использоваться при небольших расстояниях между парой объектов.

Возможные алгоритмы поиска ближайшего объекта:

- `linear` - линейный проход по всем объектам.

Примеры запуска для разных версий проекта:

Версия 1.0
```bash
./build/attractions_app -d=haversine \
                        -f=<path/to/coordinates.csv> \
                        -i=<path/to/image.jpg> \
                        -t=csv \
                        -st=linear \
                        -s
```

Версия 2.0 | 2.1 | 3.0
```bash
./build/attractions_app -d=haversine \
                        -f=<path/to/coordinates.csv> \
                        -i=<path/to/image.jpg> \
                        -t=csv_fb \
                        -st=linear \
                        -s
```

## Приложение для определения округа или региона (для РФ)

```bash
./build/search_districts_app -i=<path/to/image.jpg> \
                             -d=<path/to/districts.csv> \
                             -t=<reader_type>
```

Демонстрирует линейный поиск округа или региона, в который входит интересующая локация.

Для запуска приложения необходимо передать формат входных данных (ключ `-t`), пути до изображения
(ключ `-i`) и до файла (ключ `-d`) в формате `.csv`, содержащего базу округов или регионов.

## Приложение определения административной единицы с понижением уровня детализации (для РФ)

```bash
./build/search_admin_unit_app -i=<path/to/image.jpg> \
                              -c=<path/to/city_districts.csv> \
                              -r=<path/to/regions.csv> \
                              -t=<reader_type>
```

Демонстрирует двухэтапный поиск административное единицы, в которую входит интересующая локация:

1. Выполняется поиск округа, как самой малой доступной единицы.
1. При отсутствии результата выполняется поиск по регионам.

Для запуска приложения необходимо передать, формат входных данных (ключ `-t`), пути до изображения
(ключ `-i`) и до файлов в формате `.csv`, содержащего базу округов (ключ `-c`) и регионов (ключ `-r`).

## Приложение для разбиения базы городов на сегменты

```bash
./build/cities_grid_app -t=<reader_type> \
                        -f=<path/to/cities.csv>
```

Для запуска приложения необходимо передать формат входных данных (ключ `-t`) и путь до файла
в формате `.csv` или `.csv.fb` (ключ `-f`), содержащего базу городов.

## Приложение для поиска соседних регионов (для регионов РФ)

```bash
./build/district_neighbors_app -t=<reader_type> \
                               -d=<path/to/regions.csv>
```

Для запуска приложения необходимо передать формат входных данных (ключ `-t`) и путь до файла
в формате `.csv` или `.csv.fb` (ключ `-d`), содержащего базу регионов.

По результатам работы рядом с входным файлом создаётся файл `<regions>_neighbors.csv`,
содержащий список соседних регионов для каждого.

## Приложение для определения региона по координатам (для регионов РФ)

```bash
./build/search_admin_unit_by_coords_app -lat=<latitude> \
                                        -lon=<longitude> \
                                        -t=<reader_type> \
                                        -lf=<path/to/locations.csv> \
                                        -df=<path/to/districts.csv> \
                                        -st=<search_type> \
                                        [-dnf=<path/to/district_neighbors.csv>]
```

Определяет регион по переданным координатам без использования изображения.

Для запуска приложения необходимо передать:
- `lat`, `lon` — широта и долгота в градусах,
- `-t` — формат входных данных,
- `-lf` — файл с базой локаций (для определения ближайшего города),
- `-df` — файл с базой регионов,
- `-st` — алгоритм поиска (`linear` или `neighbors`).

Для использования алгоритма `neighbors` необходимо дополнительно передать:
- `-dnf` — файл с соседними регионами.
